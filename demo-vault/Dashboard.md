# Project dashboard

The timeline is a read-only Bases view over `Projects.base`. Planned timing is
striped; committed timing is solid. The focus strip on top is derived from the
notes themselves — nothing here is configured by hand.

![[Projects.base#Timeline]]

Switch the view menu inside the embed (or open `Projects.base`) to see the
ordinary table of the same data, which works even if the plugin is disabled.
